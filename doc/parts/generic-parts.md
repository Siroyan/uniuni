# 汎用部品（カタログv15）

型番・定格を固定せず、リードの曲げ方とパッケージを選ぶための部品。従来の44部品に24部品を追加する。

## リード間隔

抵抗 `Resistor <n>-grid`、キャパシタ `Capacitor <n>-grid`、インダクタ `Inductor <n>-grid`、ダイオード `Diode <n>-grid` を各n=2/3/4/5/6で用意する。

「nマス」はピン中心間の距離であり、Occupied幅や間に空ける穴数ではない。標準2.54mmグリッドでは5.08/7.62/10.16/12.70/15.24mm。Occupied幅は両端のピンを含むn+1セル。

| 種類 | ピン | Occupied | 参照名 |
| --- | --- | --- | --- |
| 抵抗 | 1=(0,0), 2=(n,0) | (n+1)×1 | R |
| キャパシタ | 1=(0,1), 2=(n,1) | (n+1)×2 | C |
| インダクタ | 1=(0,0), 2=(n,0) | (n+1)×1 | L |
| ダイオード | A=(0,0), K=(n,0) | (n+1)×1 | D |

キャパシタは無極性の汎用ラジアル形状。極性付きは既存のCapacitor Electrolyticを利用するか、Part Editorでピン名・外形を編集する。ダイオード画像の明るい帯は右側のK。抵抗の色帯は識別用で、抵抗値を表現しない。

## トランジスタ

既存の `Transistor TO-92` と `TO-220 3-pin` に加えて、以下を立てて実装する上面図として追加する。番号は図上の位置を示す汎用の1/2/3で、E/B/CやG/D/Sの機能は固定しない。

| 名称 | ピン1 / 2 / 3 | Occupied |
| --- | --- | --- |
| Transistor TO-18 | (0,1) / (1,2) / (2,1) | 3×3 |
| Transistor TO-39 | (1,2) / (2,3) / (3,2) | 5×5 |
| Transistor TO-126 | (1,1) / (2,1) / (3,1) | 5×2 |
| Transistor TO-247 | (1,2) / (3,2) / (5,2) | 7×3 |

金属缶は円形上面、TO-126/247はタブ・樹脂本体の上端とリードを描く。赤い印がピン1。新規トランジスタの参照名はQ。

これらは特定メーカーの寸法保証モデルではなく、リードを整数グリッドへ曲げた汎用モデル。TO-18/39の三角配置やTO-247の5.08mm間隔は実部品の公称寸法と一致するとは限らない。使用部品に合わせてPart Editorで番号・外形を調整する。表面実装SOT-23を直接挿すモデルは追加せず、既存のSOT-23-3 to DIP-4 Adapterを利用する。

## 保存・画像

- カタログv14以前のライブラリへ、不足する24部品を一度だけ追加する。同ID・同名の既存定義は上書きせず、更新後の削除も維持する。
- PNGは1セル8px。Occupiedと同じ外接サイズで、リード端はピン中心に一致する。
- `node scripts/draw-generic-parts.mjs`、`node scripts/embed-part-art.mjs` で再生成する。
