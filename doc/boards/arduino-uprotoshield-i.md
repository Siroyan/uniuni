出典: 添付 [Arduino-UProtoShieldI-20140129.pdf](../datasheets/Arduino-UProtoShieldI-20140129.pdf)。資料内の文章は基板の参考情報として扱う。

- PDF 2・7ページ: DIGITAL / POWER / ANALOG の端子表記。
- PDF 3〜6ページ: ランド配置と既設銅箔。左側はSMDランド。
- シルクの表記: 2014.01.29 V1。

## 座標と精度

穴ピッチ2.54mm、上段DIGITALの半ピッチずれ、外形の角の位置は図面比率から読み取ったもの。
原点は中央ユニバーサル領域の最左列と上段DIGITAL外側列の交点で、外形左上から概ね(14.8,1.9)mm。
68×52mmの外形寸法以外の位置寸法は図面に記載がないため概算。製造データではない。

整数グリッドの幅21・高さ20。各行の穴位置（両端を含む）:

| Y | X |
| --- | --- |
| 0 | 12〜19、および表示のみの1.5〜10.5（1刻み） |
| 1 | 1〜10、12〜19 |
| 2 | なし |
| 3〜4 | 0〜19 |
| 5〜16 | 0〜20 |
| 17 | 0〜4 |
| 18〜19 | 0〜3、5〜12、14〜19 |

中央305穴、DIGITAL36穴、POWER16穴、ANALOG12穴で合計369穴。
整数座標に一致する359穴が編集対象。右上の欠けと下部の空白を長方形の穴で埋めない。
PDFにないM3取付穴は追加しない。

## 現在の制約

上段DIGITALの半ピッチずれ10穴は描画のみ。左側SMDランドは領域表示のみ。
既設銅箔やヘッダー間の接続はNet・DRCへ反映しない。現在のCADはユーザーが描いた配線の接続を扱う。
全Pinを穴位置で検証する。本体のOccupiedは穴のない空白や基板外へ張り出せる。部品同士のOccupied衝突は基板外でも拒否する。

`board.profile` は自動保存・Undo/Redo・ZIPに含まれる。省略された既存データは従来の長方形として読める。
プロファイル導入前のアプリはこの穴配置を検証できないため、この基板のZIPは更新後のアプリで開く。
